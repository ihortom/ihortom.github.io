Multi-Timer User Guide

HOME / Multi-Timer

Multi-Timer lets you run several named countdown timers side by side, so you can keep track of more than one task at a time. You can give each timer a name and a note, and you get a notification when it finishes.

Install

  1. Download the DMG for your Mac:
    • …_arm64.dmg: Apple silicon Macs (M1 and newer)
    • …_x64.dmg: Intel Macs
  2. Open the DMG and drag Templatr into Applications.
  3. The first time you open it, macOS may say it can't verify the app. Go to System Settings → Privacy & Security, scroll down and click Open Anyway. You only need to do this once.

Getting started

When you first open Multi-Timer, it shows one empty timer. If you have deleted all your timers, you'll see the message "Hit + button above to add timer".

Each timer is a row with:

  • A time display, showing the time left
  • Quick-time buttons (1, 2, 5, 10, 20, 30, 60) and a clock button
  • A bell icon, which lights up when the timer finishes
  • A progress bar, which shrinks as time runs out
  • A control panel with a name field and the timer's own buttons

The toolbar

The toolbar across the top of the window applies to all timers:

Button What it does
➕ Add timer Adds a new empty timer at the bottom of the list.
⏹ Reset all timers Stops and clears every timer.
✖ Delete all timers Deletes every timer. You click it twice: the first click turns the icon into a trash can, and the second click deletes. If you move the pointer away before the second click, nothing is deleted.
👁 Hide inactive timers Hides every timer that isn't counting down. A banner tells you how many are hidden. Click again to show them.
🔧 Preferences Opens the settings.
ℹ About Shows the version number and checks for updates.

While Preferences or About is open, the other toolbar buttons are disabled and the timer list is hidden. Click the same button again to go back to your timers.

Setting a timer

You can set a timer in two ways.

Option 1: Set a duration with the quick-time buttons

Click a number to add that many minutes to the timer. The countdown starts right away.

Each click adds to the time already on the timer, so you can combine buttons:

  • 5 → 5 minutes
  • 5, then 5 → 10 minutes
  • 60, then 30, then 5 → 1 hour 35 minutes

You can also click a button while a timer is running to add more time.

Option 2: Count down to a time of day with the clock

Use this when something has to happen at a specific time, like a meeting at 14:30.

  1. Click the clock button (🕘) to the left of the quick-time buttons. Hour and minute fields appear.
  2. Type the hours. If the clock format is 12-hour, pick AM or PM from the drop-down next to the fields.
  3. Type the minutes.
  4. Press Enter or click the clock button again. The countdown starts.

Notes on the clock:

  • If the time you enter has already passed today, the timer counts down to that time tomorrow.
  • A field you fill in wrongly (for example, hour 25) turns red. The timer doesn't start until you fix it.
  • The quick-time buttons are disabled while the clock fields are open.
  • You can't edit the clock fields while the timer is running. Reset the timer first.

When a timer finishes

When a timer reaches zero:

  • You get a macOS notification with the timer's name.
  • The bell icon on that timer lights up.
  • The Dock icon shows a badge with the number of finished timers.
  • If sound alarm is on, the sound you picked plays (see Preferences).

To acknowledge a finished timer, click the bell. This turns the bell off, closes the notification, and lowers the Dock badge count.

Timer controls

The panel under each timer has these controls:

Control What it does
Name field Type a name, such as "Tea" or "Standup". It appears in the notification and in the note's header. Unnamed timers show up as "Timer".
⏹ Reset (red square) Stops the timer, clears its time, and closes its notifications.
📝 Note Opens the note for this timer. The button turns yellow when the note has text.
🔁 Recurring Repeats the timer. When it reaches zero, it starts again from the same duration. The button is highlighted while recurring is on.
⬆ / ⬇ Move up / down Moves the timer one place up or down the list.
✖ Delete Deletes this timer. Like Delete all, you click it twice. Move the pointer away before the second click to cancel.
Recurring timers

Recurring is useful for regular reminders, such as stretching every 30 minutes.

  1. Set a duration, for example 30.
  2. Click the Recurring button.

Each time the timer reaches zero, you get a notification and it starts another 30-minute countdown. Recurring timers don't add to the Dock badge. Click Recurring again to turn it off, or Reset to stop the timer.

Notes

Each timer can have a free-text note, for things like a ticket number, a link, or what to do next.

  1. Click the Note button. The note opens above the timer, with the time left and the timer's name in its header.
  2. Type your note. It is saved as you type.

The note header has three buttons:

Button What it does
✖ Close Closes the note. Your text is kept.
📖 / ✏ Read / Write mode Switches between editing and reading the note. In read mode, web addresses that start with http or www. become clickable links that open in your default browser.
🗑 Delete note Clears the note's text and closes it.

Reordering timers

You can reorder timers in two ways:

  • Click ⬆ or ⬇ in a timer's control panel.
  • Drag a timer up or down the list and drop it where you want it.

Preferences

Click 🔧 Preferences in the toolbar.

Setting Options Notes
Time format HH:MM / HH:MM:SS In HH:MM, the minutes are rounded up: 4 minutes 10 seconds shows as 00:05. Switch to HH:MM:SS to see seconds.
Clock format 24H / 12H Sets how you enter times in a timer's clock. 12H adds the AM/PM choice.
Theme Light / Dark Changes the app's colours.
Sound alarm OFF / ON Plays a sound when a timer finishes. When it's on, a drop-down appears where you pick the sound.

Choosing an alarm sound: Open the drop-down and hover over a sound to hear it. Click one to select it. The sounds are Default, Bonus, Facility, Futuristic, Treasure, Unlock, and Winning.

About and updates

Click ℹ About to see the app version and the components it's built with. Multi-Timer also checks whether a newer version is out:

  • "You've got the latest version": no update is needed.
  • "Version X.Y.Z is available. Download": click Download to get the installer for your Mac (Intel or Apple silicon) in your browser.

If the check can't connect, for example because you're offline, the update line doesn't appear.

What Multi-Timer remembers

When you quit and reopen the app, Multi-Timer keeps:

  • Your timers, in the same order
  • Timer names and notes
  • Which timers are hidden
  • All your preferences

It doesn't keep running countdowns. Timers open with no time set, so restart them if you need to.

Tips

  • Pomodoro: Name a timer "Focus", click 20 and 5 to set 25 minutes, then turn on Recurring.
  • Clean up the list: Use Hide inactive timers so you only see timers that are counting down.
  • Find your links quickly: Put links in a note and switch to read mode to open them with one click.
  • Use HH:MM:SS for short timers: The default HH:MM format rounds up, so a 1-minute timer shows 00:01 for most of the minute.
